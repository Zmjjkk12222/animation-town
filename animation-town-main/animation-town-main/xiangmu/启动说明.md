# 动画小镇 · 启动说明

一个以动画为主题的儿童登录/注册演示项目：**Vue 3 前端 + Spring Boot 后端 + MySQL**。

## 一键启动（推荐）

双击 `start-all.bat`，脚本会自动完成：

1. 检查 MySQL 服务（3306）
2. 首次运行时自动建库建表（`animation_town`，导入 10 条动画数据）
3. 启动后端 Spring Boot（8081 端口，首次编译约 30-60 秒）
4. 启动前端 Vite 开发服务器（5173 端口）
5. 全部就绪后自动打开浏览器

停止服务：双击 `stop-all.bat`（不会动 MySQL 服务本身）。

## 环境要求

| 依赖 | 版本要求 | 说明 |
|---|---|---|
| Java (JDK) | 17+ | 本机已装 Zulu 21 |
| MySQL | 8.x | 账号 root / 密码 123456（在 `springBootTest/src/main/resources/application-dev.properties` 修改） |
| Node.js | 18+ | 用于运行 Vite |

## 手动启动（可选）

```bash
# 1. 初始化数据库（首次）
mysql -uroot -p < springBootTest/src/main/resources/sql/animation_town.sql
mysql -uroot -p < springBootTest/src/main/resources/sql/animation_town_data.sql

# 2. 启动后端（8081）
cd springBootTest
mvnw.cmd spring-boot:run

# 3. 启动前端（5173）
cd vue
npm install   # 首次
npm run dev
```

## 常见问题

**Q：后端启动报 "Port xxxx was already in use"？**
检查是否设置了 `SERVER__PORT` 环境变量——Spring Boot 会把它当成 `server.port`。清掉即可：
`set SERVER__PORT=`（启动脚本已自动处理）。

**Q：登录提示"连不上后端"？**
确认后端窗口显示 `Tomcat started on port 8081`；前端依赖 Vite 代理（`vue/vite.config.js`）转发 `/api` 到 8081。

**Q：数据库连接失败？**
核对 `application-dev.properties` 中的 `spring.datasource.username/password` 与本机 MySQL 一致。

**Q：想换端口？**
后端改 `application-dev.properties` 的 `server.port`，同时改 `vue/vite.config.js` 代理的 `target`。
